# Recursos de marca — OdontoRisas

Coloca aquí los logos del centro. El componente `Logo` (`modules/core/ui`) elige la
variante según el tema (claro/oscuro).

Archivos esperados (PNG con transparencia, preferible):

- `logo-light.png` — logo para **fondos claros** (modo claro).
- `logo-dark.png` — logo para **fondos oscuros** (modo oscuro).

> Se pueden recortar/optimizar tras copiarlos (auto-trim de bordes transparentes).
> Si más adelante hay una versión monocroma/vector (SVG), es preferible por nitidez.
